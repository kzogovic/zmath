On the AP exam: write it so it earns credit

  • Name the distribution and its parameters: “X ~ Binomial(n = 20, p = 0.3)” or “Normal(μ = 70, σ = 4)”.
  • Write the probability you want, with the boundary: P(X ≤ 5), P(X ≥ 6), P(Z > 1.8).
  • Then give the answer: P(X ≤ 5) = 0.4164.
  • Calculator syntax by itself, such as binomcdf(20,0.3,5), does not earn credit, even when the answer is right. It's fine to show it as well, as long as you label the parameters.
  • Discrete: “at least 6” means P(X ≥ 6) = 1 − P(X ≤ 5). Continuous: < and ≤ give the same answer.
